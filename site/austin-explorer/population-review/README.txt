LOCAL REVIEW — not published
Open review.html directly in a browser; no server or internet required.
Outputs: group_comparisons.csv (all group summaries), quality_checks.csv, manifest.json.
Use selectors for destination, mode, threshold/job type, geography and population. Save chart buttons export SVG; the map exports PNG.
Methods: counts weight accessibility at H3 origins. Quantiles use the inverse weighted empirical CDF. Non-reached travel times are right-censored, never assigned the limit as an observed value; full means are blank if any weighted origins are censored. Conditional means are explicitly labeled. Missing access is excluded with coverage reported.
Low access uses the selected-area resident-weighted 75th percentile of travel time or 25th percentile of supply. Threshold ties are included, so the low-access share can exceed 25%. Zero supply thresholds select zero supply; censored time thresholds select all non-reached origins. Austin and metro each use their own distribution; a fixed threshold applies to all groups within the selected area. It is relative disadvantage, not an adequacy standard. Reference weights follow each group denominator.
ACS 2020–2024 five-year estimates allocated using 2020 Census block population crosswalks. Household/family allocation uses population as a proxy. Disability is allocated from tracts. Unmatched population cells remain unknown. Groups overlap. Boxes show weighted 25th–75th percentiles with a median line; whiskers show weighted 10th–90th percentiles. These describe distribution, not confidence intervals. Arrows mark percentiles beyond the routing limit; tails beyond whiskers are not plotted.
Austin uses existing H3 city membership, not new boundary clipping. Destination availability outside the region is unchanged. Transit represents supplied GTFS/routing coverage, not all regional service or disability-specific routing. Auto for no-vehicle households is hypothetical. Park acres are reachable inventory supply, not per-capita provision, quality or usable acreage.
Review source models and service calendar before treating these outputs as final. Prior capped summaries and the public website are not modified; this folder supersedes them for this demographic review only.
