End-to-end workflow

The workflow keeps source preparation, routing, accessibility calculation, QA, and delivery distinct enough to audit or replace independently.

Define origins and geography

Select the study boundary, origin units, coordinate system, population weights, modes, and departure periods. Preserve origins with no reachable destination.

Build opportunity inventories

Prefer authoritative sources. Retain source snapshots, standardize fields, geocode, deduplicate, screen eligibility, and record manual decisions.

Prepare or ingest travel times

Use a suitable routing source for each mode. Record dates, departure windows, cutoffs, percentiles, walking assumptions, and geographic coverage.

Declare measures

The case-study YAML registry connects origins, inventories, modes, periods, opportunity fields, and plain-language measures.

Calculate accessibility

The shared runner uses the R accessibility package to apply the same measure definitions to each mode-specific matrix.

Validate and deliver

Check coverage, service calendars, exclusions, duplicates, unreachable origins, and distributions before publishing tables, spatial layers, maps, and manifests.
