# Attribution and project relationship

This repository contains work developed by Md. Hamidur Rahman for destination
preparation and multimodal accessibility analysis within the Austin Opportunity
Index research collaboration.

Parts of the repository structure and accessibility preparation code were
adapted from the MIT-licensed `aakarner/atx-opportunity-index` repository,
copyright 2026 Alex Karner. The original MIT notice is retained in `LICENSE`.

Austin-specific data preparation methods also rely on public source agencies
identified in the destination documentation. Data products remain subject to
their source terms. Licensed DataAxle exports are excluded from this public
repository.
